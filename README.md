# Employee Data Cleaning and Analysis in Excel
## Overview
This project demonstrates an end-to-end data analysis workflow using Excel For The Web, from raw data cleaning and transformation through exploratory analysis, PivotTables, data visualisation, and dashboard development. 

The primary purpose of this project is to demonstrate the process of preparing, analysing, visualising, and communicating data using Excel.

The project uses a publicly available dataset called Messy Employee Dataset which contains data-quality issues for cleaning and analysis practice.

Dataset Source: https://www.kaggle.com/datasets/desolution01/messy-employee-dataset 

The workbook is divided into four worksheets to clearly separate the original data, cleaning process, exploratory analysis, and final dashboard.

## Workbook Structure
### 1. Raw Data
This is the original dataset as obtained from Kaggle.

The raw data has been preserved separately to ensure that the original source remains unchanged and can be compared with the cleaned dataset.

### 2. Working Sheet
The raw dataset was cleaned and transformed in Excel to improve data quality and prepare it for analysis. This involved addressing duplicate records, inconsistent formatting and values, invalid entries, and restructuring fields where necessary. Additional variables, including age groups, were created to support the analysis.

### 3. Pivot Tables
PivotTables and visualisations were used to explore employee demographics, performance, salary, work arrangements, and location-based patterns. The findings from this exploratory analysis informed the selection of the key visualisations presented in the final dashboard.

### 4. Dashboard

This contains four selected visualisations designed to provide a concise overview of the dataset. 

- No. Of Employees Per Department: provides an overview of workforce composition and makes it easy to identify departments with larger and smaller employee populations.
- Performance Score Distribution by Work Arrangement: compares performance score distributions between remote and in-person employees. The purpose of this analysis was to investigate whether employee performance distributions differed according to work arrangement.
- Percentage of Employees Rated Excellent by Department: This chart compares the percentage of employees receiving an Excellent performance rating within each department.
- Average Salary Per Location: compares average employee salaries across locations and departments.

## Key Observations

- Remote and in-person employees showed broadly similar performance distributions. In-person employees had slightly higher proportions of both Excellent and Poor ratings, suggesting differences were concentrated at the extremes rather than indicating consistently higher performance.
- HR had the highest proportion of employees whose performance was rated Excellent
- Average salaries varied considerably across departments and locations. The most notable variation occurred within Finance, where average salaries in Illinois and Nevada were particularly low compared with other locations.
